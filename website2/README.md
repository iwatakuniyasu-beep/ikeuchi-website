# IKEUCHI 若者向け POP デザイン 3案（website2）

以前の5案（`../website`）とは別に、若い人向けのポップなデザインを3案つくりました。
`website` フォルダには手を加えていません。

## フォルダ構成

```
website2/
├── index.html            ← 3案の見比べページ（まずこれを開く）
├── 01-zine/index.html    ← 案1: 鉄ZINE（ネオ・ブルータリズム）
├── 02-liquid/index.html  ← 案2: LIQUID METAL（Y2K × クローム、ダーク）
├── 03-bento/index.html   ← 案3: てつのおべんとう（パステル × アプリ風）
└── assets/
    ├── video/hero/       ← 短いループ動画（ページ内で自動再生）
    ├── video/films/      ← フル尺の映像（クリックで再生）
    ├── poster/           ← 動画のサムネイル、CG／実物の比較画像
    ├── photo/            ← 作品写真（展示写真・暮らしの鉄）
    └── js/lightbox.js    ← 写真・動画をクリックで拡大する仕組み（3案共通）
```

`assets` は `website/assets` からコピーしたものです（元のファイルはそのまま残っています）。

## 見かた

フォルダ内の `index.html` をダブルクリックでも見られます。動画の自動再生がブロックされる場合は、
`C:\temp\Ikeuchi` で次を実行して `http://localhost:8001` を開いてください。

```
python -m http.server 8001 --directory website2
```
