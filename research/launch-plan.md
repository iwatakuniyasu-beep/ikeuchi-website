## 1. スタートまでのスケジュール（2026年10月〜2027年7月）

**7月スタートは時期として良い**です。夏は屋外（グランピング・キャンプ場・ビアガーデン・テラス）の需要が高く、結婚式場は秋の繁忙期（9〜11月）に向けて夏に装飾を決めるので、その提案にも間に合います。

| 時期 | やること | 担当の目安 |
|---|---|---|
| **2026年10月** | ・屋号（サービス名）を決める（例：「IKEUCHI IRON RENTAL」）<br>・SNSアカウントをまとめて取る（Instagram／TikTok／YouTube／Facebookページ／LINE公式。名前をそろえる）<br>・AIツールを無料版で試す | 本人 |
| **11月** | ・**作品の棚卸し**：貸し出せる作品を10〜20点選び、作品カードを作る（写真・寸法・重さ・素材・仕上げ・屋内か屋外か・評価額）<br>・撮影機材をそろえる<br>・SNS投稿スタート（制作過程が中心） | 本人＋AI |
| **12月** | ・専門家に相談：税理士（個人か法人か、経費、インボイス）、行政書士か弁護士（レンタル契約書の雛形）、保険代理店（動産総合保険＋賠償責任保険の見積もり）<br>・料金表のたたき台を作る | 本人＋専門家 |

| **2月** | ・運搬の準備（車、台車、毛布・梱包材、2人で運ぶ体制）<br>・設置マニュアル（固定方法、チェックリスト、貸し出し時の写真記録）<br>・契約書の雛形ができる | 本人 |

| **6月** | ・**開業の手続き**（下の表）<br>・事業用の銀行口座、請求書・領収書のひな形、会計ソフト<br>・**先行予約・モニター募集**（7月開始の先着◯社は初回の設置費無料など）<br>・SNSでカウントダウン | 本人＋税理士 |
| **7月** | ・**サービス開始**。開始記念キャンペーン<br>・設置先とのコラボ投稿<br>・地域の新聞・ケーブルテレビ・タウン誌にプレスリリースを送る | 本人＋AI |
| 8月〜 | ・毎月SNSの数字を確認して改善<br>・秋冬（結婚式・クリスマス・年末年始）の入れ替え提案 | |

### 開業の手続き（6〜7月）
| 手続き | 期限・ポイント |
|---|---|
| 開業届（税務署） | 事業を始めてから1か月以内 |
| 青色申告承認申請書 | 開業から2か月以内に出せば、その年から青色申告（特別控除）が使える |
| インボイス（適格請求書発行事業者）登録 | 法人のお客さんが多いならほぼ必要。登録を希望する日の15日前までに申請。免税事業者からの登録は「2割特例」が使える場合あり（税理士に確認） |
| 古物商許可 | 自分の作品だけを貸すなら基本的に不要。中古の作品を仕入れて貸すなら必要 |
| 保険 | 動産総合保険（作品）＋施設賠償・PL保険（ケガ）。試験設置の前に入るのが理想 |

※ 池内さんがすでに作家として開業届を出している場合は、事業内容の追加などで済むことがあります。

## 2. SNSを使った販促の方法

### どのSNSを何に使うか
| SNS | 役割 | 内容 |
|---|---|---|
| **Instagram（メイン）** | 認知・実績を見せる・問い合わせ | リール（短い動画）、作品写真、設置事例のカルーセル（複数枚の写真）、ストーリーズ |
| **TikTok／YouTubeショート** | 新しい人に見つけてもらう | Instagramのリールをそのまま流用。溶接の火花や鉄を叩く音は強い |
| **YouTube（長い動画）** | 信頼・作家の人柄 | 制作のドキュメンタリー（月1本でOK）。営業資料にリンクを貼れる |
| **Facebookページ／LinkedIn** | 会社の担当者・経営者向け | 導入事例、「なぜ受付にアートを置くのか」など法人向けの文章 |
| **Pinterest** | インテリアデザイナー・設計事務所に見つけてもらう | 設置イメージの写真をボードにまとめる |
| **LINE公式アカウント** | 問い合わせの窓口・既存のお客さんへの連絡 | 入れ替えのお知らせ、見積もり相談 |

### 投稿の6つの柱
1. **制作過程**：火花、鉄を叩く・曲げる、溶接の音。言葉がなくても伝わり、一番伸びやすい
2. **ビフォーアフター**：作品を置く前と後で空間がどう変わるか。法人の担当者が社内で説明するときの材料になる
3. **作品紹介**：作品の周りをぐるっと回る映像、照明で変わる影、錆が育っていく経年変化のタイムラプス
4. **業種別の提案**：「ホテルのロビーに置くと」「式場のフォトスポットに」。AIで作った設置イメージを使う（必ず「イメージ」と表記）
5. **作家のストーリー**：池内さんの考え、作品名の由来、工房の日常
6. **導入先の声**：設置したお店・式場のコメント、お客さんの反応

### 投稿の頻度（目安）
- リール：週3本（TikTok・YouTubeショートにも同じものを投稿）
- 写真・カルーセル：週2本
- ストーリーズ：ほぼ毎日（工房の様子、制作途中など気軽なもの）
- YouTubeの長い動画：月1本（余裕があれば）

### 時期ごとの作戦
| 時期 | 目的 | 中心の投稿 |
|---|---|---|
| 2026年11月〜2027年2月 | 知ってもらう・フォロワーを集める | 制作過程、作品紹介、作家のストーリー |
| 3〜5月 | 実績を見せる | 試験設置のビフォーアフター、設置先とのコラボ投稿、業種別の提案 |
| 6月 | 期待を高める | カウントダウン、先行予約・モニター募集、料金やサービスの説明 |
| 7月〜 | 問い合わせを増やす | 開始記念キャンペーン、導入事例、少額の広告 |

### 法人のお客さんに届けるコツ
- **設置先とのコラボ投稿**（Instagramの「コラボ」機能）：お店・式場のフォロワーにも表示される。設置先にとっても宣伝になるので頼みやすい
- **地域名のハッシュタグ**（#◯◯市ホテル #◯◯結婚式場 など）と業種のハッシュタグを組み合わせる
- プロフィールのリンクは「相談フォーム」に直結させる
- フォロワー数よりも**保存数・プロフィールへのアクセス・問い合わせ数**を見る
- 気になる施設には、投稿にいいね・コメントで関係を作ってから丁寧なDMや資料送付をする（いきなり売り込まない）

### AIを使うときの注意
- **作品そのものをAIで作り変えない**。実物と違うものを見せると信用を失い、誇大広告にもなりかねない。AIは「設置イメージ」「編集」「字幕」「ナレーション」に使う
- AIで作ったリアルな映像には「AI生成のイメージ」と書く。Instagramなどには、AIで作った内容に付ける表示（AIラベル）の仕組みもある
- BGMは、各SNSやツールで使ってよいとされている音源だけを使う

## 3. AIエージェントでの動画制作と、月ごとの経費

### 仕組み（週1回の撮影 → あとはAIがまとめる）
1. **池内さんが撮る（週1回・30分〜1時間）**：スマホで制作中の様子や作品をそのまま撮る。ここだけは人間にしかできない
2. **AIエージェント（Claude や ChatGPT）**：その週の投稿計画、台本、キャプション、ハッシュタグ、英語版の文章を作る。月1回はSNSの数字を見て改善案も出す
3. **編集AI（CapCut）**：自動カット、字幕、BGM、縦型への変換
4. **動画生成AI（Kling／Google Veo など）**：「ホテルのロビーに置いたら」などの設置イメージを作る
5. **予約投稿**：Meta Business Suite（無料）で Instagram・Facebook の投稿を予約。TikTok・YouTube は各アプリの予約投稿機能を使う

※ 投稿までの完全自動化もできなくはないですが、作品の見え方を確認するために**最後の確認と投稿ボタンは人が押す「半自動」**をおすすめします。
