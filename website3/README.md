# IKEUCHI 高級ラウンジ向け 2案（website3）

ターゲット：高級ラウンジ・会員制バーなどのオーナー。
「池内の作品を店内のオブジェとして置きたい」と思ってもらうためのサイトです。

```
website3/
├── index.html              ← 2案の見比べページ
├── 01-nocturne/index.html  ← 案A：Nocturne（体験で惹きつける）
├── 02-selection/index.html ← 案B：Selection（選びやすさで後押し）
└── assets/                 ← 写真・ポスター・短いループ動画・lightbox.js
```

## 2案のちがい

| | A：Nocturne | B：Selection |
|---|---|---|
| 狙い | 「夜の店でこう見える」という感動で欲しくさせる | 「自分の店にはこれが合う」と迷わず選べるようにする |
| 見た目 | 黒×金、明朝体、暗い店内のような画面 | 生成り×深緑×真鍮、雑誌・家具カタログ風 |
| 主な仕掛け | カーソルがスポットライトになるトップ／置く場所別の提案（入口・カウンター・VIP・吹き抜け）／照明シミュレーション（開店前・営業中・深夜）／スタッフが語れる「一言」／CGと実物の比較スライダー | 4つの質問で作品をおすすめ（◎○△）／選んだ条件がそのまま相談メールになる／比較表／導入の流れと準備するものリスト |

## 素材について

- 守るべきもの・問う・植物の写真は、元動画（`movie` フォルダ）から文字の入っていないコマを切り出したものです
  （`assets/photo/*-clean.jpg`）。以前のポスター画像には動画のタイトル文字が入っていたため差し替えました。
- 守るべきもの・問う・白卵・炎の映像は YouTube（限定公開）を再生します。無題のみサイト内の動画ファイルです。

## 確認してほしいこと

- 価格・サイズ・納期・レンタルなどの条件は、確認できていないため載せていません。載せる場合は内容を教えてください。
- 「スタッフの一言」（案A）や「おすすめの場所・照明」は、作品の特徴から考えた提案文です。作家の意図と違う点があれば直します。
- 「花と石」「無題」などの作品名は仮のものを含みます。
