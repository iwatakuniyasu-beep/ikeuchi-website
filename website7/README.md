# IKEUCHI ブライダル・イベント向け レンタル 2案（website7）

結婚式場ではフォトスポットやオブジェが会場の魅力として打ち出されており、イベントでは会期だけの装飾レンタルが一般的です。

```
website7/
├── index.html            ← 2案の見比べページ
├── 01-photospot/index.html   ← 案A：Photo Spot
├── 02-event/index.html   ← 案B：Event
└── assets/               ← 写真・ポスター・短いループ動画・lightbox.js（website3 からコピー）
```

| | 案A：Photo Spot | 案B：Event |
|---|---|---|
| キャッチ | ふたりの写真に、一生残る背景を。 | イベント会場に、足を止める“鉄の主役”を。 |
| 中身 | アイボリー×ブラッシュのエレガント。スマホ画面の中で写真の写り方を見せ、色調（クラシック／ナチュラル／ナイト）を切り替え。 | 赤×黒のポスター風。会期の長さと会場を選ぶと、搬入〜撤去の段取り・おすすめ作品・確認事項が出ます。屋外展示の実例つき。 |

## 共通の注意点

- レンタルの期間・料金・保険・破損時の扱いなどは決まっていないため、すべて「ご相談」と表記しています。
- 掲載作品が実際にレンタルに出せるかは未確認のため、「レンタル可否は作品の設置状況により異なります」と注記しています。
- ベンチ・収納・ハンガーの写真は「設置イメージ」と表記しています。
- YouTube の映像は使っていません（写真中心）。
