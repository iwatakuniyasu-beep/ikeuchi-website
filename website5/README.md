# パブリックアートレンタル アイル　オフィス・企業向け 2案（website5）

2026-10-22 の指示書（PDF）に沿って、2案とも上部を作り替えました。下の既存部分（来訪者の動線・レンタルの理由・新着の作品・導入の流れ・お問い合わせ）はそのまま残しています。

```
website5/
├── index.html              ← 2案の見比べページ
├── 01-entrance/index.html  ← 案A：Kiwi Maru × 生成り・オレンジ、作品写真が1列で流れる
├── 02-workplace/index.html ← 案B：Zen Maru Gothic × ミント、作品写真が2列で左右に流れる
├── works/                  ← 作品ごとのページ（19作品・2案共通）
└── assets/
```

## 指示書との対応

| 指示 | 実装 |
|---|---|
| サービス名「パブリックアートレンタル アイル」、親しみのあるフォント | ページ上部の大見出しとロゴ。案A＝Kiwi Maru、案B＝Zen Maru Gothic |
| スペース①：作品の画像がオートでスクロール | 作品写真が横に自動で流れる（マウスを乗せると止まる）。写真を押すと作品ページへ |
| 春・夏・秋・冬のボタンで作品が切り替わる | ボタンで流れる作品が切り替わり、色も季節に合わせて変わる。開いたときは今の季節 |
| スペース②：作者の経歴表 | 作家の経歴（1961年〜）と、作品・受賞歴の表 |
| 作成年度と受賞タイトル | 表の「作成年度」「受賞タイトル／設置場所」列 |
| 受賞タイトルがない作品は設置場所を明記 | 受賞なしは「設置」として設置場所を表示。設置場所も不明なものは「出品」として展覧会名 |
| 作品のページに飛ぶボタン | 各行の「作品ページ →」。作品ページは works/ に19ページ |

- 作成年度が不明な作品（湧昇の夢・卵・彩りの鉄・植物・復興芽図・ミノムシ・丘の上の植物）は「─」「確認中」と表示しています。
