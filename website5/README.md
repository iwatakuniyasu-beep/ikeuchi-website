# IKEUCHI オフィス・企業向け レンタル 2案（website5）

法人向けのアートレンタル（ClubFm、between the arts、ARTerrace RENT など）が国内でも広がっている業種です。

```
website5/
├── index.html            ← 2案の見比べページ
├── 01-entrance/index.html   ← 案A：Entrance
├── 02-workplace/index.html   ← 案B：Workplace
└── assets/               ← 写真・ポスター・短いループ動画・lightbox.js（website3 からコピー）
```

| | 案A：Entrance | 案B：Workplace |
|---|---|---|
| キャッチ | 受付は、会社の名刺だ。 | 社員が話したくなるオフィスへ。 |
| 中身 | 紺×オレンジのコーポレート。来訪者の動線（エレベーター→受付→待合→会議室）に沿って作品を提案。レンタルと購入の比較表つき。 | ミント×イエローのやさしい雰囲気。来月の作品を社員投票で選ぶデモと、社内で楽しむアイデア集。 |

## 共通の注意点

- レンタルの期間・料金・保険・破損時の扱いなどは決まっていないため、すべて「ご相談」と表記しています。
- 掲載作品が実際にレンタルに出せるかは未確認のため、「レンタル可否は作品の設置状況により異なります」と注記しています。
- ベンチ・収納・ハンガーの写真は「設置イメージ」と表記しています。
- YouTube の映像は使っていません（写真中心）。
