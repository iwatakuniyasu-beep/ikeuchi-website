# IKEUCHI 商業施設・ショップ向け レンタル 2案（website8）

ウィンドウディスプレイやポップアップストアは、季節やキャンペーンごとに装飾を入れ替える期間限定の使い方が中心の分野です。

```
website8/
├── index.html            ← 2案の見比べページ
├── 01-window/index.html   ← 案A：Window
├── 02-popup/index.html   ← 案B：Pop-up
└── assets/               ← 写真・ポスター・短いループ動画・lightbox.js（website3 からコピー）
```

| | 案A：Window | 案B：Pop-up |
|---|---|---|
| キャッチ | 通りを歩く人が、思わず振り返るウィンドウを。 | ポップアップの世界観に、手仕事の鉄を一点。 |
| 中身 | 深緑×真鍮のアールデコ百貨店風。新作・ギフト・サマー・ホリデーを選ぶとショーウィンドウの演出が変わります。 | 白×オレンジのモダン。ブランドのトーンを選ぶとムードボード（色・言葉・作品）が組み変わり、そのまま相談メールに。 |

## 共通の注意点

- レンタルの期間・料金・保険・破損時の扱いなどは決まっていないため、すべて「ご相談」と表記しています。
- 掲載作品が実際にレンタルに出せるかは未確認のため、「レンタル可否は作品の設置状況により異なります」と注記しています。
- ベンチ・収納・ハンガーの写真は「設置イメージ」と表記しています。
- YouTube の映像は使っていません（写真中心）。
