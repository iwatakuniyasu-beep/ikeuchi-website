# IKEUCHI ホテル・旅館向け レンタル 2案（website4）

ロビーの展示を会期ごとに入れ替えるホテルの例（京王プラザホテルのロビーギャラリーなど）があり、季節替え・展示替えと相性がよい業種です。

```
website4/
├── index.html            ← 2案の見比べページ
├── 01-seasons/index.html   ← 案A：四季
├── 02-gallery/index.html   ← 案B：Lobby Gallery
└── assets/               ← 写真・ポスター・短いループ動画・lightbox.js（website3 からコピー）
```

| | 案A：四季 | 案B：Lobby Gallery |
|---|---|---|
| キャッチ | 季節が、ロビーに来る。 | ロビーを、小さな美術館に。 |
| 中身 | 藍×生成りの和の世界観、縦書き。春夏秋冬を選ぶとページの色とおすすめ作品が切り替わり、入れ替えカレンダーとプランを紹介。 | 白い美術館風。期間と置き場所の数を選ぶと、会期ごとの展示計画（作品の入れ替え表）ができます。 |

## 共通の注意点

- レンタルの期間・料金・保険・破損時の扱いなどは決まっていないため、すべて「ご相談」と表記しています。
- 掲載作品が実際にレンタルに出せるかは未確認のため、「レンタル可否は作品の設置状況により異なります」と注記しています。
- ベンチ・収納・ハンガーの写真は「設置イメージ」と表記しています。
- YouTube の映像は使っていません（写真中心）。
