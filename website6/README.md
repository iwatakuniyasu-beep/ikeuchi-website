# IKEUCHI モデルルーム・住宅展示場向け レンタル 2案（website6）

ホームステージング（見学者が暮らしを想像できるよう空間を整えること）で、家具や装飾をレンタルする考え方が一般的な分野です。

```
website6/
├── index.html            ← 2案の見比べページ
├── 01-blueprint/index.html   ← 案A：Blueprint
├── 02-lifescene/index.html   ← 案B：Life Scene
└── assets/               ← 写真・ポスター・短いループ動画・lightbox.js（website3 からコピー）
```

| | 案A：Blueprint | 案B：Life Scene |
|---|---|---|
| キャッチ | 見学者の記憶に残るモデルハウスには、一点の作品がある。 | 「ここに住んだら」を、一点の作品が語りはじめる。 |
| 中身 | 青焼き図面風。間取り図の部屋をクリックすると、おすすめ作品と置き方が出ます。公開期間に合わせたレンタル期間の図つき。 | 暮らしの雑誌風。朝・昼・夕方・夜を選ぶと暮らしの場面が変わります。庭・家族・プレミアムのステージングセットを提案。 |

## 共通の注意点

- レンタルの期間・料金・保険・破損時の扱いなどは決まっていないため、すべて「ご相談」と表記しています。
- 掲載作品が実際にレンタルに出せるかは未確認のため、「レンタル可否は作品の設置状況により異なります」と注記しています。
- ベンチ・収納・ハンガーの写真は「設置イメージ」と表記しています。
- YouTube の映像は使っていません（写真中心）。
